# Chrome Profiles

Type a URL or a search, then pick the Chrome profile that opens it. An empty
search opens a new tab. ⌘↵ opens a new window instead.

Profiles come from Chrome's `Local State`, so the list matches Chrome's own
profile picker on both Linux and macOS.

## Install

- **vicinae (Linux):** `npm install && npm run build`
- **Tinycast (macOS):** `npm install && npm run build:tinycast`, then in Tinycast
  Settings → Extensions → Install New → Add from folder → `dist-tinycast/`.
  Rebuild and add it again after changing the source.
